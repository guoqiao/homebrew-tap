# homebrew-tap

Personal Homebrew tap for formulae and casks.

## Installation

```bash
brew tap guoqiao/tap
```

## Formulae

Install CLI tools:

install Modern Unix CLI tools (metapackage)
```
brew install --HEAD guoqiao/tap/clis
```

install MLX Audio Server (macOS only, with service support)
```bash
brew install guoqiao/tap/mlx-audio-server
```


## Casks

Install fonts:

```bash
brew install --cask guoqiao/tap/fonts
```

Install apps:

```bash
brew install --cask guoqiao/tap/apps
```
